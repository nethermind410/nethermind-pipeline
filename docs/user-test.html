NETHER User Test

Step 6: three people, five tasks each, about 30 minutes per person. Notes save in this browser only. Use "Download notes" to keep them.

Before each session

  1. Start NETHER with the demo channel (fresh setup, no real keys needed).
  2. Pick testers who have never seen NETHER and ideally make or want to make Shorts.
  3. Ask them to think out loud. Don't help, point, or explain. If they're stuck for 2 minutes, mark "Needed help" and give the smallest hint.
  4. Read the words in the quote boxes exactly, so all three hear the same thing.
"We're testing the app, not you. If something is confusing, that's our problem to fix. Please say what you're thinking as you go."
